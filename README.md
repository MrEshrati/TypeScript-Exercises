# TypeScript Exercises

Three browser exercises for learning how TypeScript interacts with HTML and the DOM.

| Exercise | What it covers |
| --- | --- |
| [Calculator](First-Exercise%20%28Calculator%29/) | Button handlers, a numeric display, and arithmetic |
| [Move Your Mouse](Second-Exercise%20%28Move%20Your%20Mouse%29/) | Pointer events, coordinates, and color changes |
| [Drag and Drop](Third-Exercise%20%28Drag%20and%20Drop%29/) | An exercise scaffold with markup, styles, and an empty TypeScript file |

## Run locally

Open the calculator or mouse exercise's `index.html` to use its checked-in JavaScript. After changing TypeScript, run `tsc js/script.ts` from the exercise directory with the TypeScript compiler installed to rebuild the JavaScript beside the source.
